# 🛠️ SESI Manutenção Osasco

Sistema profissional de controle de estoque de materiais de manutenção desenvolvido para o SESI Osasco, focado no gerenciamento de materiais, movimentações e organização do almoxarifado.

---

## 📌 Funcionalidades

### 🔐 Autenticação
- Login com **NIF + senha**
- Primeiro acesso
- Recuperação de senha
- Controle de acesso por perfil (Administrador e Funcionário)

### 📦 Controle de Materiais
- Cadastro de materiais
- Edição de materiais
- Controle de estoque
- Categorias
- Estoque mínimo

### 📥 Movimentações
- Entrada de estoque
- Saída de estoque
- Retirada de materiais
- Histórico completo de movimentações

### 👥 Funcionários
- Cadastro de funcionários
- Controle de permissões
- Perfil do usuário
- Histórico individual

### 📊 Dashboard & Relatórios
- Dashboard Administrativo
- Dashboard do Funcionário
- Relatórios gerenciais
- Indicadores visuais do estoque
